## なぜ2種類あるか

PowerPoint で開く環境によってフォントやレイアウトが崩れるため、
最終版は各スライドを画像に焼いてある（"safe" の由来）。
そのぶん**画像版は中身を編集できない**ので、編集用のテキスト版を残している。

修正が必要になったら **テキスト版を直す → 画像版を作り直す** の順。
画像版だけを直そうとしないこと。
