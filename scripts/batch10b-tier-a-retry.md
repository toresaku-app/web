## 1. side-plank — サイドプランク → `side-plank-v3.png`

構図基準: **`plank.png`**（前腕支持の描き方の手本。※現行の `side-plank.png` は参照に使わない）

前回の失敗: 下側の腕が拳のまま前方に伸び、肘が肩の真下になかった。腰も浮いて見えず、
横向きに寝ているだけの絵のままだった。

```
【運動】サイドプランク（Side Plank）

この絵の主役は「下側の前腕で体を支えている」ことです。そこを最優先で描いてください。

- 横向きに寝た姿勢から、【下側の前腕を床に置いて上体を持ち上げている】
- 【肘は肩の真下】。上腕は床に対してほぼ垂直に立つ
- 前腕は床にべったり接し、手は握らず自然に開く
- 【腰・骨盤を床から持ち上げ】、頭・体幹・骨盤・脚が一直線
- 床に接しているのは「下側の前腕」と「下側の足の外側」の2点だけ。
  【腰の下に床との隙間がはっきり見えること】
- 上側の手は骨盤の上に置く。両脚は伸ばして重ねる
- 視点: 横から（側面図）

赤い矢印: 骨盤の下から真上へ。腰を持ち上げる方向。

【やってはいけない】
- 腰を床につけたまま横向きに寝ている絵にしない（前回はこれ）
- 下側の腕を前方にまっすぐ伸ばさない。肘を曲げて肩の真下に置く
- 手を握り拳にしない
- 破線・補助線を入れない。使う線は赤い矢印だけ
```

**検収**: 肘が肩の真下か / 腰の下に隙間が見えるか / 前腕が床に接しているか / 拳になっていないか

## 2. chest-stretch — 胸郭ストレッチ → `chest-stretch-v3.png`

構図基準: **`wall-pushup.png`**（肘を曲げて垂直面に体重を預ける描き方の手本。
※現行の `chest-stretch.png` は参照に使わない）

前回の失敗: 両足接地は直ったが、腕がまっすぐ上外に伸びたままで、
肘が肩の高さで90度に曲がっていなかった。前腕もドア枠に接していない。

```
【運動】胸郭ストレッチ（Chest Stretch）

この絵の主役は「肘を肩の高さで90度に曲げ、前腕をドア枠に当てている」ことです。

- ドア枠（青い縦の枠が左右に2本、間が通路）の中に立つ
- 【両肘を肩と同じ高さまで上げ、そこで90度に曲げる】。
  上腕は床と水平、前腕は床から垂直に立てる（いわゆる「両手を挙げて降参」の形）
- 【前腕の内側の面をドア枠にべったり当てる】。手のひらも枠に接する。拳を握らない
- 【肘の高さは肩と同じ。肩より上に上げない】
- 片足を一歩前に踏み出したスプリットスタンス。【両足とも足裏全体が床に接地】
- その姿勢から体を前へ出し、胸を開いている
- 視点: 正面やや斜め前から

赤い矢印: 胸の中央から前方（通路を進む向き）へ。

【やってはいけない】
- 腕をまっすぐ上外に伸ばさない。必ず肘を90度に曲げる（前回はこれ）
- 手だけを枠につけない。前腕を面で当てる
- 人物を宙に浮かせない。両足を床につける
```

**検収**: 肘が90度か / 肘の高さが肩と同じか / 前腕が枠に面で接しているか / 両足接地か

## 3. tandem-stance — タンデム立位（継ぎ足） → 2枚

構図基準: **`tandem-stance-start-v2.png`**（人物・椅子はこのままでよい）

前回の失敗: 姿勢自体（踵とつま先の接触）は正しく描けていた。
しかし**全身の正面図**にしたため、印刷実寸（64×48mm）では足元が小さな白い塊になり、
この運動の核心である接触点が読めなかった。矢印もモノクロでほぼ消えた。

**今回変えるのは画角だけ。** 姿勢は前回のままでよい。

```
【共通の画角指示】※2枚とも同じ

- 【腰から下を大きく描く】。頭から足先までを収めなくてよい。
  上半身は胸のあたりで画面外に切れてよい
- 【足元が画面の下半分を占める】くらい大きく描く
- 視点: 【斜め前方のやや高い位置から見下ろす】。
  両足の前後関係と、足と足が接している位置がはっきり分かる角度にする
- 椅子は青いパイプ椅子。背もたれに添えた手は画面内に残す
- 赤い矢印は【太く大きく】。実寸に縮小しても、モノクロにしても残る太さにする
```

**3-a. 開始** → `tandem-stance-start-v3.png`
```
両足を左右に並べて揃えて立っている（まだ継ぎ足にしていない）。
片手は青いパイプ椅子の背もたれに添えている。
矢印は入れない。
```

**3-b. 動作** → `tandem-stance-v3.png`
```
【前足の踵が、後ろ足のつま先にぴったり接して、両足が一直線上に並んでいる】。
踵とつま先が触れている一点が、絵の中で最も分かりやすい要素になるように描く。
片手は椅子の背もたれに添えたまま。
赤い矢印: 後ろ足のつま先から前足の踵へ向かう太い矢印。接触点を指す。
```

**検収**: 実寸64×48mmに縮小しても踵とつま先の接点が分かるか /
モノクロにしても矢印が残るか / 2枚の画角・人物の大きさが揃っているか
