## 生成ルート

ChatGPT に1枚ずつ。**参照画像を必ず2枚添付する**（これが今回の肝）。

1. **人物基準**: `assets/illustrations/originals/shoulder-shrug.png` を毎回添付する
   - 顔・年齢のばらつきが今回のレビューで判明したため。ライブラリの多数派はこの顔
   - 法令線のある中年男性・短髪黒髪・やや重い顎。若く平坦な顔にしない
2. **構図基準**: 運動ごとに指定した画像を添付する（下の各項に明記）
3. 出力: `assets/illustrations/originals/{id}.png`（既存を上書きせず別名で作り、検収後に差し替え）
4. **出力サイズは構図基準の画像と同じピクセル寸法に揃える**

### 共通スタイル指示（毎回、個別プロンプトの前に入れる）

```
添付した2枚の画像と同一シリーズの運動イラストを1枚作成してください。

【添付画像の役割】
- 1枚目（人物基準）: この人物の顔・年齢・体型・服装を使う。ポーズは真似しない
- 2枚目（構図基準）: この視点・画角・人物の大きさ・小道具の描き方に揃える

【最重要ルール】
- 人物は1枚目と同一人物に見えること。中年男性で、若く平坦な顔にしない
- 対象となる関節「だけ」が動いている絵にする。
  それ以外の関節・支持物・足の位置・道具の位置は構図基準から動かさない
- 出力サイズは2枚目と同じピクセル寸法にする

【スタイル】
- セミリアリスティックなフラットイラスト
- 白背景、影なし
- 人物: 中年男性、短髪黒髪、白い半袖Tシャツ、紺のハーフパンツ、白い靴下
- 輪郭線: 細い黒線
- 色数: 最小限（肌色、白、紺、青）
- 運動の動作方向を示す赤い矢印（太め、はっきり見える）
- 補助具（椅子・タオル・枕・台・棒）は青色。椅子は青いパイプ椅子で統一する
- 医療的に正確な関節角度と体の向き
- 余計なテキストや文字は入れない
```

## 個別プロンプト

### 1. ankle-dorsiflexion — 足関節背屈運動 → `ankle-dorsiflexion.png`

構図基準: `ankle-dorsiflexion-start.png`（この開始姿勢は正しい。ここから足首だけを変える）

```
【運動】足関節背屈運動（Ankle Dorsiflexion）
青いパイプ椅子に背筋を伸ばして座り、両膝は約90度のまま。
片足の【踵を床につけたまま】、つま先と前足部だけを天井に向かって持ち上げている瞬間。
下腿は構図基準の画像とまったく同じ位置・同じ角度のまま動かさない。
視点: 構図基準と同じ横から（側面図）。
赤い矢印: つま先の先端付近から真上へ向かう短い矢印。

【やってはいけない】
- 膝を伸ばさない。脚を前方に持ち上げない（現行版はこれを間違えている）
- 足を床から浮かせない。踵は必ず床に接したまま
```

検収: 膝が90度のままか / 踵が床についているか / 変化しているのが足首だけか

### 2. ankle-plantarflexion — 足関節底屈運動 → `ankle-plantarflexion.png`

構図基準: `ankle-plantarflexion-start.png`

```
【運動】足関節底屈運動（Ankle Plantarflexion）
青いパイプ椅子に背筋を伸ばして座り、両膝は約90度のまま。
片足の【つま先・前足部を床につけたまま】、踵だけを持ち上げて足首を伸ばしている瞬間
（座位でのカーフレイズ）。ふくらはぎに力が入っている様子が分かるように。
下腿は構図基準の画像とまったく同じ位置のまま、足首の角度だけが変わる。
視点: 構図基準と同じ横から（側面図）。
赤い矢印: 踵の後ろから真上へ向かう短い矢印。

【やってはいけない】
- 膝を伸ばさない。脚を前方に投げ出さない（現行版はこれを間違えている）
- 足全体を床から浮かせない。前足部は床に接したまま
```

検収: 膝90度のままか / 前足部が接地しているか / 踵が浮いているか

### 3. tandem-stance — タンデム立位（継ぎ足） → 2枚

構図基準: `hip-extension-start.png`（青いパイプ椅子の後ろに立ち、背もたれに手を添える構図）

**3-a. 開始** → `tandem-stance-start.png`
```
【運動】タンデム立位（継ぎ足）の開始姿勢
青いパイプ椅子の横に立ち、片手を椅子の背もたれに軽く添えている。
両足は肩幅よりやや狭く、左右に並べて揃えて立っている（まだ継ぎ足にしていない）。
背筋はまっすぐ、視線は正面のやや下。
視点: 斜め前方から、足元がはっきり見える高さ（やや高い位置から見下ろす角度）。
足元が画面内で十分大きく見えるように、人物は膝から下を大きめに描く。
矢印は入れない（開始姿勢のため）。

【必ず守る】椅子は青いパイプ椅子。木製の椅子にしない
```

**3-b. 動作** → `tandem-stance.png`
```
【運動】タンデム立位（継ぎ足）
開始姿勢と同じ位置に立ち、同じ手を椅子の背もたれに添えたまま。
【前足の踵が、後ろ足のつま先にぴったり接して、両足が一直線上に並んでいる】瞬間。
踵とつま先が接している一点が、絵の中で明確に読み取れること。これがこの運動の核心。
背筋はまっすぐ、視線は正面のやや下。
視点・人物の大きさ・椅子の位置は開始姿勢とまったく同じ。
赤い矢印: 後ろ足のつま先から前足の踵へ向かう短い矢印（一直線に並べることを示す）。

【やってはいけない】
- 単に片足を前に踏み出しただけにしない。足の間に隙間を作らない（現行版はこれを間違えている）
- 椅子から手を離さない
```

検収: 踵とつま先の接点が見えるか / 両足が一直線か / 開始と動作で椅子・人物の位置が同じか

### 4. hip-flexor-stretch — 股関節屈筋ストレッチ → `hip-flexor-stretch.png`

構図基準: `hip-flexor-stretch.png`（現行版。姿勢は正しい。矢印と人物だけ直す）

```
【運動】股関節屈筋ストレッチ（Hip Flexor Stretch）
片膝立ち（ランジ姿勢）。人物は画面の左を向いている。
前脚（画面左側）は膝を約90度に曲げて足底を床につけ、
後ろ脚（画面右側）は膝を床につけ、膝の下に青く畳んだタオルを敷いている。
背筋はまっすぐ伸ばし、上体は前傾させない。
重心を【前方＝画面左】へ移動し、後ろ脚の股関節前面が伸びている瞬間。
視点: 横から（側面図）。
赤い矢印: 骨盤の高さから【画面左（人物が向いている方向）】へ向かう水平の矢印。

【やってはいけない】
- 矢印を画面右（後方）に向けない。現行版はこれを間違えており、
  伸ばす方向と逆を指示してしまっている
- 上体を丸めない
```

検収: 矢印が人物の向いている側（左）を指しているか / 背筋がまっすぐか

### 5. gait-backward — 歩行訓練（後退） → `gait-backward.png`

構図基準: `gait-forward.png`（手すりの描き方が良い例。ただし進行方向は逆にする）

```
【運動】歩行訓練（後退）
横に手すり（青い水平のバー、腰の高さ）があり、片手を手すりに添えている。
人物は画面右を向いて立ち、【視線と体は前方＝画面右のまま】。
その姿勢のまま【後ろ向き＝画面左へ歩いている】瞬間。
後方へ運んでいる脚は、【つま先から床に接地する】ところ（踵はまだ浮いている）。
つま先接地がはっきり分かるように足元を描く。
視点: 横から（側面図）。
赤い矢印: 床の高さで、後方へ運ぶ足から【画面左】へ向かう矢印。

【やってはいけない】
- 顔・体・矢印をすべて同じ向きにしない。現行版はこれを間違えており、
  完全に前進歩行に見えてしまっている
- 手すりが人物の胴体を横切って見えないように、手すりは人物の手前ではなく
  奥側（背中側）に配置し、添えている手との接点を明確に描く
- 靴は履かせない（白い靴下。現行版は運動靴を履いている）
```

検収: 矢印が体の向きと逆か / つま先接地が見えるか / 手すりが胴体を横切っていないか / 靴下か

### 6. knee-extension-rom — 膝関節伸展ROM訓練 → `knee-extension-rom.png`

構図基準: `knee-extension-rom.png`（現行版。タオルの位置は正しい。矢印だけ直す）

```
【運動】膝関節伸展ROM訓練（Knee Extension ROM）
仰向けに寝た状態。片脚の【踵の下】に青く丸めたタオルを置き、
踵が持ち上がって膝の裏に隙間ができている。
その膝を伸ばし、【膝の裏を床に押しつけている】瞬間。
反対の脚はまっすぐ伸ばして床につけている。
視点: 横から（側面図）。
赤い矢印: 【膝の真上】から膝の裏・床に向かって真下を指す矢印。

【やってはいけない】
- 矢印を足首・下腿の遠位に置かない。現行版はこれを間違えており、
  「踵をタオルに押しつける」運動に読めてしまう
- タオルは踵の下。膝の下に置かない
```

検収: 矢印が膝の真上にあるか / タオルが踵の下にあるか

### 7. side-plank — サイドプランク → `side-plank.png`

構図基準: `plank.png`（同系統の体幹支持系。人物の大きさ・画角の基準）

```
【運動】サイドプランク（Side Plank）
横向き（側臥位）で、【下側の前腕を床につけて上体を支えている】。
肘は肩の真下に置く。
【腰を床から持ち上げて】、頭・体幹・骨盤・脚が一直線になっている瞬間。
床に接しているのは「下側の前腕」と「下側の足の外側」の2点だけ。
上側の手は骨盤の上に置く。両脚は伸ばして重ねる。
視点: 横から（側面図）。腰が床から浮いていることが明確に分かるように。
赤い矢印: 骨盤の下から真上へ向かう矢印（腰を持ち上げる方向）。

【やってはいけない】
- 床に寝かせない。腰・骨盤は必ず床から浮かせる（現行版は寝ているだけになっている）
- 肘を肩から離さない
- 青い破線などの補助線を入れない。このシリーズで使う線は赤い矢印だけ
```

検収: 腰が浮いているか / 肘が肩の真下か / 接地が前腕と足の外側の2点だけか / 破線がないか

### 8. chest-stretch — 胸郭ストレッチ → `chest-stretch.png`

構図基準: `wall-pushup.png`（壁に対して立つ構図・人物の大きさの基準）

```
【運動】胸郭ストレッチ（Chest Stretch）
ドア枠（青い縦の枠が左右に2本、間が通路）の中に立っている。
【両方の前腕をドア枠の内側の面にぴったり当てている】。
肘は【肩と同じ高さで約90度】に曲げ、手のひらは枠に接している（拳を握らない）。
片足を前に踏み出したスプリットスタンス（前後開脚）で、
【両足とも足の裏全体が床についている】。
その姿勢から体を前方へ出して胸を開いている瞬間。
視点: 正面やや斜め前から。
赤い矢印: 胸の中央から【前方（通路を進む向き）】へ向かう矢印。

【やってはいけない】
- 人物を宙に浮かせない。片脚を高く上げない（現行版は走っているように見える）
- 前腕を枠から離さない。手を握り拳にしない
- 肘を肩より高く上げない
```

検収: 両足が接地しているか / 前腕が枠に接しているか / 肘が肩の高さで90度か

### 9. forearm-stretch — 前腕ストレッチ → `forearm-stretch.png`

構図基準: `wrist-flexion.png`（座位で腕を前に伸ばす構図の良い例）

```
【運動】前腕ストレッチ（Forearm Stretch）
【青いパイプ椅子に座った状態】。背筋を伸ばしている。
片腕を体の前に肩の高さでまっすぐ伸ばし、【肘はしっかり伸ばしたまま】、
手のひらを下に向けている。
【反対側の手で、伸ばした側の指先を掴んで手前・下方向へ引いている】瞬間。
引かれた側の手首は手のひら側に曲がり、前腕の外側（伸筋群）が伸びている。
2本の腕が重ならず、掴んでいる手の位置がはっきり見えるように描く。
視点: 横から（側面図）。
赤い矢印: 指先から【手前・下方向】へ向かう矢印（引く方向）。

【やってはいけない】
- 立位で描かない。現行版は立位に見えるが、この運動は座位（`posture: "座位"`）
- 反対の手を省略しない。現行版は引く手が描かれておらず、
  誰も引いていない絵になっている
- 矢印を上向き（指先を戻す方向）にしない
```

検収: 椅子に座っているか / 反対の手が指先を掴んでいるか / 肘が伸びているか / 矢印が下・手前向きか
